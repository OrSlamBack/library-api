# 📚 MyLibrary API

REST API для управления домашней библиотекой. Позволяет добавлять книги, просматривать их, обновлять информацию и удалять записи.

Проект написан с использованием **чистой архитектуры** (разделение на роутеры, репозитории, модели и схемы) и полностью упакован в **Docker**.

## 🛠 Стек технологий

* **Python 3.11** — язык программирования
* **FastAPI** — современный веб-фреймворк для создания API
* **SQLAlchemy 2.0** — ORM для работы с базой данных
* **PostgreSQL 16** — реляционная база данных
* **Pydantic** — валидация данных и сериализация
* **Docker & Docker Compose** — контейнеризация и запуск

## 🚀 Как запустить проект

Самый простой способ запустить проект — использовать Docker.

1. Убедитесь, что у вас установлен **Docker Desktop**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/OrSlamBack/library-api.git
   ```
3. Запустите проект одной командой:
   ```bash
   docker-compose up --build
   ```
4. API будет доступно по адресу: `http://127.0.0.1:8000`
